# 获客短视频脚本（~60s 口播）
**标题**：每天早上，NASA 的天文大图和最近的小行星，自动出现在你的智能家庭屏上

1. （0-3s 钩子）：你的 Home Assistant 仪表盘还在只显示温度和灯？给它加点宇宙级浪漫。
2. （3-12s 演示）：每天早上 6 点，这个 n8n 工作流自动从 NASA 拉当天的天文一图——今天拍的是土星系统全家福。
3. （12-25s 流程）：同时它查未来三天掠过地球的小行星，按距离排序，把最近那颗的名字、距离、速度、危不危险，全部推上仪表盘。
4. （25-40s 结果）：看效果——标题、解说自动清洗成 280 字摘要，距离自动换算成"几倍地月距离"，一目了然。
5. （40-55s 钩子2）：全程零付费——NASA 两个接口都免费，没有 Home Assistant 我也教你用 30 行 Python 本地验证。模板的 3 个坑我全替你踩完了。
6. （55-60s CTA）：回复暗号【天文】领完整课程包，含修复版工作流。

**画面建议**：HA 仪表盘实拍 → n8n 流程平移 → APOD 美图轮播 → 小行星数据卡片 → 坑列表快闪。
